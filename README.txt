This project uses python 3 

Running code:

to run the code, while running a terminal window in your working directory enter the command: 
python3 turtlecode.py


you will then be prompted to select among the algorithms bfs, dfs, A* or greedy best-first,
enter 'b' for bfs,
enter 'd' for dfs
enter 'a' for A*
enter 'g' for greedy bf

Stop code:

to stop execution, on the next prompt, click "Cancel"

The benchmark maze used is apart of maze_solver.py to try a new maze, replace the maze in code.
